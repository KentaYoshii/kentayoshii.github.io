{%- comment -%}
Rendered from docs/_data/travel.json, generated by scripts/build_travel.py.
site.data.travel.checklists is a dict keyed by whatever json key each
category in scripts/build_travel.py's CHECKLISTS registers — this loop
renders however many there are without knowing their names, so adding a new
category (Countries, say) needs no change here, only in build_travel.py.
Unlike Books/Movies this needs no client-side search or grouping — each
checklist is small enough to fit on one screen — so the whole page is
server-rendered and works with no JavaScript at all.
{%- endcomment -%}
