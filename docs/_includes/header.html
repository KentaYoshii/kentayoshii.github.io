{%- comment -%} Overrides minima's default header, which lists every header_pages entry in one flat row — fine at five pages, cramped once Gallery made it seven. The markup below is minima's own header.html (same classes: site-header, wrapper, site-nav, nav-trigger checkbox, menu-icon, trigger, page-link) so none of the existing CSS or the mobile hamburger behaviour has to change — only nav_pages render inline as before, and nav_more_pages (_config.yml) sit behind a "More" toggle, opened by initMoreMenu() in main.js. Below $on-palm the checkbox-driven .trigger panel already *is* the "opened menu", so a second, nested disclosure inside it would be clutter rather than compaction. main.scss instead flattens .nav-more-menu on mobile (always visible, no toggle button) so it reads as the tail of one plain list there. {%- endcomment -%}
